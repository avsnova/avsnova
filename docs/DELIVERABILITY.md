# Email Deliverability Guide — Aurevashop / AVSLogs

Sender domain: **avslogs.org** · Main sender: **hello@avslogs.org** · Mail host: **SpaceMail (mail.spacemail.com)**

Application-side deliverability is already handled in code:
- A consistent, authenticated **From** (`"Aurevashop Support" <hello@avslogs.org>`) and **Reply-To** (`hello@avslogs.org`).
- Well-formed multipart **HTML + plain-text** emails with a standardized header/footer.
- A `List-Unsubscribe` header and `X-Auto-Response-Suppress` header on every message.
- Purpose-based SMTP aliases so OTP / notifications / marketing can use distinct identities.

The remaining requirement — **SPF, DKIM, and DMARC** — must be configured as **DNS records** at your domain host (these cannot be set from application code). Add the following records for `avslogs.org`.

---

## 1. SPF (authorizes SpaceMail to send for your domain)

Add ONE `TXT` record on the root domain. If you already have an SPF record, merge — do **not** create a second one.

| Type | Host / Name | Value |
|------|-------------|-------|
| TXT  | `@` (avslogs.org) | `v=spf1 include:spacemail.com ~all` |

> Confirm the exact `include:` value with SpaceMail's docs (some use `include:_spf.spacemail.com`). Only one SPF TXT record may exist per domain.

## 2. DKIM (cryptographically signs your mail)

DKIM keys are generated by SpaceMail. In the SpaceMail control panel, enable DKIM for `avslogs.org`; it will give you a selector and a public key. Add it as a `TXT` (or `CNAME`, depending on what SpaceMail provides) record:

| Type | Host / Name | Value |
|------|-------------|-------|
| TXT  | `<selector>._domainkey.avslogs.org` | `v=DKIM1; k=rsa; p=<PUBLIC_KEY_FROM_SPACEMAIL>` |

Example host: `default._domainkey` or `spacemail._domainkey` — use the selector SpaceMail shows you.

## 3. DMARC (policy + reporting; ties SPF/DKIM together)

Add ONE `TXT` record:

| Type | Host / Name | Value |
|------|-------------|-------|
| TXT  | `_dmarc.avslogs.org` | `v=DMARC1; p=quarantine; rua=mailto:hello@avslogs.org; ruf=mailto:hello@avslogs.org; fo=1; adkim=s; aspf=s; pct=100` |

Start with `p=quarantine` (or `p=none` for a monitoring-only warm-up period), then move to `p=reject` once you've confirmed SPF+DKIM pass for all your mail via the `rua` aggregate reports.

---

## 4. Verify

After DNS propagates (up to 24–48h):
1. Use the Admin → **Email Center → Connections → Verify (real-time OTP)** button to confirm live send+receive.
2. Send a test to a Gmail address and check **Show original** → SPF/DKIM/DMARC should all say **PASS**.
3. Optional external checks: [mail-tester.com](https://www.mail-tester.com), [mxtoolbox.com](https://mxtoolbox.com/deliverability).

## 5. Extra tips
- Keep sending volume steady during the first weeks (domain reputation warm-up).
- Ensure a valid **PTR / reverse DNS** on the sending IP (SpaceMail manages this for hosted mail).
- Avoid spammy subject lines and all-image emails; the templates already include a text part.
